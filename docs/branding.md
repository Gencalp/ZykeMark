# ZykeMark Branding

## Tokens
Brand colors are defined in `src/ZykeMark.Core/Brand/brand.tokens.json` and must be referenced as the single source of truth.

## Usage Rules
- **Purple** is for primary actions and headers.
- **Orange** is for warnings and highlights.
- Avoid random hardcoded colors in code; use the token file instead.
- Follow WCAG contrast guidance: aim for a 4.5:1 contrast ratio for normal text.
